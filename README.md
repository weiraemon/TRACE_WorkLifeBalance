# ATLAS — 明确下一步的个人工作台

单用户、本地运行，以独立业务线组织下一步行动。普通 Markdown 目录是唯一权威数据源，无需安装 Obsidian；Notes 保存批注、会议纪要和探索结论。MIT。

## 运行

Windows、Node.js >=22.12、本地 NTFS、Chrome / Edge：

```powershell
npm ci
npm run build
npm start
```

访问 http://127.0.0.1:4317，选择 Markdown 工作目录。开发使用 `npm run dev`，Ctrl+C 停止服务。示例目录 `examples/workspace-vault` 已采用新结构，也可向空目录生成当天示例：

```powershell
npx tsx scripts/sample-vault.ts E:\ATLAS-Trial
```

## 使用

| 页面     | 操作                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 今日     | 先写“要做什么”，再选择业务线，快速创建 TODO／IDEA；记录实际时间、关联条目、填写批注 |
| 工作空间 | 管理项目、独立业务线、截止节点及下一步；完整安排日期与归属                          |
| 知识     | 列出、筛选、新建和打开笔记或资料，不提供文件预览                                    |
| 回顾     | 查看实际投入、完成事项、等待反馈与周复盘                                            |

项目 → 业务线 → 节点 → TODO／IDEA 是最大管理深度，条目不能无限套娃。每条业务线自动建立一个待办池和一份专属 Notes。未选具体节点的条目进入待办池，无日期时不混入今日计划。

节点仅有截止日期和时刻；条目可有独立日期，无时刻，未填日期时沿用节点日期。节点标签默认会议、讨论、专注、实验、审阅，可输入新标签。重要性只用五种颜色表示。

节点、TODO、IDEA 的右键菜单提供编辑、删除、添加批注、完成及升级为业务线。升线继承项目、标题和重要性，成为独立的平级业务线，不留来源关联；对应 Notes 内容自动移入新线。节点升线保留已有截止点和活动标签；无截止要求的条目进入新线待办池。

TODO、IDEA 使用一个完成事实。所有条目完成后节点自动完成；也可以快速完成或重新打开整个节点。待办池不完成。业务线和项目必须手动完成，不因节点完成而自动关闭。

节点与条目快速删除；业务线和项目删除需要额外确认。删除解除实际关联，保留实际时间与 Notes 正文，不因历史引用阻止整理。删除不提供逐操作撤销，必要时先创建手动快照。

## Notes

节点创建或右键添加的纪要、TODO／IDEA 创建或推进时的批注，写入所属业务线 Notes：

- 二级标题带节点日期、时刻和名称。
- 三级标题带 TODO／IDEA 的种类和名称。
- 正文保存完整纪要和批注，条目详情读取同一份原文。
- 纯关联、计时或完成不生成纪要，不为每个条目创建笔记。

业务线详情可阅读、编辑 Notes 全文。节点、条目详情阅读相应部分，右键添加批注。系统保留自由正文、其他 Frontmatter 字段，冲突时拒绝覆盖并保留草稿。

## 实际工作

必填仅开始、结束和具体事件。可选关联多个 TODO／IDEA、填写逐条批注、勾选本次完成；支持在同一表单快速创建条目。表单取消不发布这些新条目。

同一条目可被多段工作关联，一段时间关联多个条目仍只计算一次。完成事实保存在条目中，不保存另一份完成关联或实际记录修订数组。时间线支持拖动、拉伸与补录，拒绝重叠。

## 数据与验证

仅支持当前 `project / workline / milestone / todo / actual / resource / review` 七种类型；`todo.kind` 区分 TODO／IDEA。不保留旧格式兼容或迁移工具。

短期跨文件日志只保存待发布内容及预期版本，完成后删除；中断后重新连接安全继续。日志不是操作备份。手动快照最多三份，普通编辑、删除、恢复不生成备份。

```powershell
npm test
npm run build
npm run test:e2e
```

文件测试需要 NTFS 硬链接和 Junction 权限。Playwright 默认使用已安装 Chrome，Edge 可设置 `ATLAS_BROWSER_CHANNEL=msedge`。测试仅使用临时目录，不寻找用户工作目录。

## 实现边界

Markdown 的稳定 ID 用于改名后定位；资源还可按唯一内容指纹查找。多文件操作有中断恢复，但无法保证任意外部编辑器并发下的绝对事务隔离；发生冲突需先保留草稿并核对文件。手动快照不覆盖普通附件，也不代替整个目录的备份。
