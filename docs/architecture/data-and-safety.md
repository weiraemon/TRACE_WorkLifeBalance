# 当前数据与安全

## 权威数据与契约

普通 Markdown 工作目录是唯一权威数据源，Obsidian 不是运行依赖。ATLAS 管理字段保存在顶层 `atlas.managed: true` 和 `atlas.record`，稳定 UUID 不随路径变化。YAML AST 只替换 ATLAS 字段，保留其他字段、注释及自由正文。

只支持当前七类：project、workline、milestone、todo、actual、resource、review。todo.kind 为 todo 或 idea，二者归属 milestoneId；节点归属 lineId，业务线归属 projectId。不保存完整祖先路径，不做无限嵌套。

旧状态枚举、工作对象说明副本、预计时长、实际修订数组和两套实际关联已移除。completedAt 是唯一手动完成事实；普通节点有子条目时通过其完成事实推导完成。项目与业务线不按下级自动完成。

actual 仅保存日期、起止时间、事件与 itemIds。completeIds 是保存命令中的瞬时操作参数，不进入 Markdown；执行后更新条目的 completedAt。完成与实际关联分开，重新打开条目不需要修改旧实际记录。

## 业务线、池和 Notes

每条业务线创建时一次发布业务线、待办池、专属 Notes。池是 pool=true 的无期限节点，固定线末端；不可单独完成、删除、升线或移动。业务线 notesId 指向单文件 resource，笔记 noteId 指向自身。

节点截止日期、时刻成对校验，不允许仅设置时刻。条目可选独立日期，不设时刻，未填则从节点推导。标签是可输入的活动字符串，不是节点系统用途或状态。

Notes 保存实质正文。节点以二级标题包含日期、时刻、名称；条目以三级标题包含 TODO／IDEA 和名称。段落使用稳定受管标记定位，批注请求 ID 避免重复追加。纯计时、关联、完成不添加段落。

批注正文只在 Notes 保存一次。实际记录不重复保存批注，条目不积累独立过程数组。节点与条目详情按标记读取同一段原文，业务线编辑完整 Markdown。自由正文不按自然语言猜测切分。

升线保留对象 ID，原位转换为 workline，继承项目、标题、重要性并建立新池、Notes。节点有日期或标签时在新线保留对应要求节点，下属条目改归该节点；否则改归新池；条目升线解除对应实际关联。原线的相应 Notes 段落移入新 Notes，不保留替身或来源边。其他段落与自由正文保留。

## 发布与冲突

工作对象、Notes、完成更新、删除解绑等跨文件修改先检查预期哈希，再写入 `.atlas/pending.json`，逐文件原子发布，完成后删除日志。日志仅含预期哈希和待发布的新内容，没有逐操作备份或撤销能力。

再次连接时，恢复日志允许文件仍为预期旧哈希或已发布的新哈希；出现第三种内容时停止，拒绝覆盖。发布中断后禁止继续提交其他操作，需重新连接完成恢复。外部修改冲突在发布前或逐文件替换时报告。

新文件通过临时文件 fsync 与硬链接发布，禁止覆盖同名文件；既有文件最后检查哈希后原子替换。无法保证任意外部进程并发下的绝对跨文件事务隔离；发生外部修改时保留文件及日志供核对。

## 删除、快照与恢复

节点与条目快速删除；项目、业务线由 UI 列出范围并额外确认。删除检查完整子集和每个 revision，解除实际与资源引用，保留实际时间和 Notes 文字；受管归属标记转为普通正文，不留下失效对象 ID。删除业务线不连带删除 Notes。

只有手动快照，最多三份。编辑、删除、恢复不自动创建备份；没有回收区或逐操作撤销。快照包含受管理 Markdown 及其正文，不包含普通笔记、附件，也不自动删除快照之后新建的记录。恢复检查当前版本冲突。

## 访问边界

- 服务只监听本机，同源 Host / Origin 校验、随机会话 token 和目录会话 ID 均保留。
- 每段路径拒绝越界、符号链接、Junction、ADS、尾点和尾空格；不扫描 .git、.obsidian、.atlas、node_modules。
- 文件锁禁止两个 ATLAS 服务同时写一个目录，目录切换后旧窗口停止读写。
- 非法 UTF-8、重复 UUID、未闭合或非法 YAML 明确诊断，不静默解码替换或覆盖。
- 只打开常见文档、目录及 http(s) 链接，不执行工作目录中的程序或脚本；Obsidian URI 由服务构造。
- 仅当前新契约，无兼容、后台迁移或真实旧目录搜索。仓库示例已完成一次性更新。
