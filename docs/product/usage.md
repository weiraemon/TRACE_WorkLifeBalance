## 使用

成功连接工作目录后，路径保存在本机 `.chaos.local.json`，下次启动服务时自动恢复；恢复失败时保留路径与原因。异常退出遗留的锁按进程存在性及启动标识安全回收。

齿轮“备份”入口内可切换暖绿／静蓝主题，浏览器会记住选择。今日左侧提示逾期未完成的 TODO，可批量顺延到今天或删除；顺延超过节点日期的待办进入同一业务线的末端待办池，保留批注。

| 页面     | 操作                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| 今日     | “今天要做”统一列出节点与待办，优先显示定时节点；“今日已做”录入实际工作，侧栏查看已记录片段 |
| 工作空间 | 管理项目、独立业务线、截止节点及下一步；完整安排日期与归属                                 |
| 知识     | 复用业务导航，选择业务线后按 Markdown 层级阅读该线 Notes                                   |
| 回顾     | 用周投入柱图、项目分布和只读计划／实际时间线回看工作                                       |

项目 → 业务线 → 节点 → TODO／IDEA 是最大管理深度，条目不能无限套娃。每条业务线自动建立一个待办池和一份专属 Notes。未选具体节点的条目进入待办池，无日期时不混入今日计划。

工作空间只隐藏截止日期超过两天且已完成的普通节点；按本地日期计算，恰好两天前的节点仍显示。未完成节点无论过期多久都保留，有条目时按全部 TODO／IDEA 的完成情况判定。未定日期和待办池保持显示。左侧勾选「显示较早已完成节点」可重新查看。今日的过期事件也保留较早未完成节点；隐藏仅影响展示，不改写日期、完成状态、Notes 或实际记录。

今日列表统一排列当天节点与条目：未完成项中，有时刻的优先按时刻排列，同一时刻按重要性从高到低；无时刻节点和待办混排，按重要性从高到低。已完成项的排序权重视为 0，立即置底，原重要性不变。节点深色底、待办普通底色，所属业务线显示在名称上方，可通过文字下拉筛选业务线。悬浮、键盘聚焦或点击节点可预览全部所属 TODO／IDEA，包括完成和其他日期的条目。右侧快速新增 TODO 默认安排到查看日期；IDEA 默认无日期。桌面今日页分为联络侧栏、当天安排、实际录入三栏，列宽不会随展开或编辑改变。联络侧栏上方显示当天联络，下方显示“已记录”，两部分各自滚动；中间只看当天安排。右侧通过同一行“今日已做 / 待办·节点”切换新增模式，选中项加深，内容左右滑动，切换保留各自未保存的输入。“待办／节点”顶部直接粘贴消息并自动匹配时间、业务线、重要性和标签，下方标题、归属、日期、标签、重要性和批注直接展示，可核对修改后添加，无需展开设置。方向键与 Home／End 可切换，减少动态效果设置下不播放滑动。待做行固定 48px，长标题省略并可悬浮查看全文。

工作空间可用鼠标拖动标题：业务线拖到另一条线上下调整顺序，拖到项目内更换项目；节点拖到其他业务线；TODO／IDEA 拖到其他条目上下排序，或拖到节点、待办池内更换归属。落点会显示插入线或虚线框，松开后自动保存，按 Esc 可取消。节点继续按截止日期排列，待办池固定在线尾。移动保留原 ID、实际关联及日期，相关 Notes 正文随归属移动；未完成 TODO 的独立日期晚于目标节点日期时，进入目标业务线待办池并提示。也可通过右键“编辑”更换归属。

节点仅有截止日期和时刻；条目可有独立日期，无时刻，未填日期时沿用节点日期。标签与日期并排放在节点上方，可选会议、报告、讨论、专注、实验、审阅或输入新标签；无标签为圆点，有标签以气泡、靶心、文档等线性图标表示。重要性在新增主要区域直接选择，默认绿色（不急），只用五种颜色表示。

节点、TODO、IDEA 的右键菜单提供编辑、删除、添加批注、完成及升级为业务线。升线继承项目、标题和重要性，成为独立的平级业务线，不留来源关联；对应 Notes 内容自动移入新线。节点升线保留已有截止点和活动标签；无截止要求的条目进入新线待办池。

TODO、IDEA 使用一个完成事实。所有条目完成后节点自动完成；也可以快速完成或重新打开整个节点。待办池不完成。业务线和项目必须手动完成，不因节点完成而自动关闭。

节点与条目快速删除；业务线和项目删除需要额外确认。删除解除实际关联，保留实际时间与 Notes 正文，不因历史引用阻止整理。删除不提供逐操作撤销，必要时先创建手动快照。

## Notes

节点创建或右键添加的纪要、TODO／IDEA 创建或推进时的批注，写入所属业务线 Notes：

- 二级标题带节点日期、时刻和名称。
- 三级标题带 TODO／IDEA 的种类和名称。
- 正文保存完整纪要和批注，条目详情读取同一份原文。
- 纯关联、计时或完成不生成纪要，不为每个条目创建笔记。

业务线详情可阅读、编辑 Notes 全文。节点、条目详情阅读相应部分，右键添加批注。系统保留自由正文、其他 Frontmatter 字段，冲突时拒绝覆盖并保留草稿。

## 实际工作

今日“今日已做”先填写具体事件与起止时间，表单明确标注记录日期，历史日期显示提示；展开“关联节点或待办（可选）”后可按业务线筛选。也可在左侧节点或待办旁点“记一段”，保留已输入内容并带入关联。关联不等于完成，“本次完成”需单独勾选；“成果 / 下一步”中的批注写入所属 Notes。新增 TODO／IDEA 或节点统一使用右侧“待办 / 节点”页签；“今日已做”仅录入实际工作并关联已有内容，切换保留输入。已保存的片段在联络侧栏下方按时间倒序展示，每段右侧点“修改”可更正日期、起止时间、正文与关联。修改保留记录 ID 与已有 Notes，关联与本次完成仍分别表达；时间重叠或文件外部修改时拒绝保存并保留表单输入。

同一条目可被多段工作关联，一段时间关联多个节点和条目仍只计算一次。完成事实保存在条目中，不保存另一份完成关联或实际记录修订数组。保存拒绝重叠时间。

关联选择保留“待添加”和“已添加”两部分，加入后可移除并重新加入。已添加的节点也提供“本次完成”：无条目会议可直接完成；有条目时会明确显示数量，并随记录保存完成全部下属 TODO／IDEA，节点由此推导完成。仅关联不会完成，清空或取消不会写入；业务线和项目仍需手动结束。

回顾显示本周投入、完成条目与工作片段数量，每日柱图可切换查看日期，项目条形图展示时间分布。原计划／实际时间线完整移至回顾，仅供查看，不支持新增、拖动、拉伸或右键编辑。当天实际记录会在时间线之外完整展示，并提供“修改”入口，避免短时间片段遮住正文；无记录时可直接跳转本周有记录的日期。时间线自动滚动到首条计划或实际记录之前。今日与回顾的查看日期独立，返回今日和 Ctrl+K 默认回到当天。已有周复盘正文保留并只读展示。编辑窗口大小固定、内部滚动；工作详情覆盖在页面右侧，不挤压原内容。

## 数据与验证

仅支持当前 `project / workline / milestone / todo / actual / resource / review` 七种类型；`todo.kind` 区分 TODO／IDEA。不保留旧格式兼容或迁移工具。

短期跨文件日志只保存待发布内容及预期版本，完成后删除；中断后重新连接安全继续。日志不是操作备份。手动快照最多三份，普通编辑、删除、恢复不生成备份。

```powershell
npm test
npm run build
npm run test:e2e
```

文件测试需要 NTFS 硬链接和 Junction 权限。Playwright 默认使用已安装 Chrome，Edge 可设置 `ATLAS_BROWSER_CHANNEL=msedge`。测试仅使用临时目录，不寻找用户工作目录。

## 实现边界

Markdown 的稳定 ID 用于改名后定位；资源还可按唯一内容指纹查找。多文件操作有中断恢复，但无法保证任意外部编辑器并发下的绝对事务隔离；发生冲突需先保留草稿并核对文件。手动快照不覆盖普通附件，也不代替整个目录的备份。
