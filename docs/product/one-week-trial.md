# 一周试用

复制 `examples/workspace-vault` 到本地 NTFS 测试目录，ATLAS 与 Obsidian 打开同一路径。

| 天  | 真实使用                                | 核对                                                    |
| --- | --------------------------------------- | ------------------------------------------------------- |
| 1   | 建项目、业务线、一个关键节点和一条待办  | 只填标题能保存，上下级归属自动带入，Obsidian 可直接读取 |
| 2   | 加讨论 / 审阅节点，设置节点日期、重要性 | 节点颜色、日期和待办列表清楚，项目能收缩                |
| 3   | 在今日补录实际工作，勾选完成待办        | 只需三项必填，实际落盘，待办联动完成                    |
| 4   | 改实际时间并撤回完成勾选                | 历史可查，重叠被拒绝，待办恢复，无两份状态              |
| 5   | 给节点加 To 和 From 待办                | 今日按联系人汇总交接与催收，明天待办不混入当天          |
| 6   | 在工作空间调整日期或移动业务线          | 今日清单和项目归属跟随关系更新，不重复填写              |
| 7   | 看本周实际投入和完成事项，写周复盘      | 未关联及跨项目耗时明确列出，快照可恢复                  |

每天只记一句问题：`触发步骤 → 期望 → 实际 → 影响 → 文件 / 截图`。检查新增弹窗是否仍有可省掉的输入，记录是否让继续工作更快。

涉及文件冲突时保留原 Markdown、备份 ID 和错误提示，先停止同一文件的并发编辑。试用结束创建管理数据快照，并独立备份整个 Vault。当前没有旧数据迁移，不在真实 Vault 中批量清理旧内容。
