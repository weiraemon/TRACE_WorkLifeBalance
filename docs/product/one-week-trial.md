# 一周试用

复制 examples/workspace-vault 到本地测试目录；普通 Markdown 编辑器即可使用，Obsidian 可选。

| 天  | 场景                                 | 核对                                                |
| --- | ------------------------------------ | --------------------------------------------------- |
| 1   | 建项目和业务线                       | 自动有一个待办池和专属 Notes，无多档状态            |
| 2   | 首页先写想法再选择业务线             | 无时间也能收集 TODO／IDEA，默认进池，不混入今日计划 |
| 3   | 创建会议节点并填写纪要               | 标签可输入，Notes 带节点日期、时刻与名称            |
| 4   | 实际记录关联两个条目并写批注         | 同一时段只计一次，原文只在 Notes，关联不自动完成    |
| 5   | 将 TODO、IDEA 或节点升成业务线       | 无重复表单、无来源边，批注移到新 Notes              |
| 6   | 完成节点、重新打开条目、删除无用关系 | 节点可推导完成，业务线必须手动；实际时间和纪要保留  |
| 7   | 手动完成业务线、创建快照并恢复       | 默认空间收起已完成线，快照最多三份，无逐次撤销      |

每天只记一个具体使用问题：触发步骤、期望、实际、影响。检查本次操作是否帮助明确下一步，避免为了完整历史而增加输入。
