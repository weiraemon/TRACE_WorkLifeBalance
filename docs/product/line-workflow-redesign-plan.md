# 独立业务线改造边界与验收

本轮以用户最终六点边界及 AGENTS.md 为准，替换早期关于未归属收件箱、仅 IDEA 升线和逐条独立 Notes 的方案。

## 交付范围

1. 删除通用状态、重复完成来源、实际记录修订数组与无用字段。
2. TODO、IDEA、普通节点均能快速升为平级业务线，不保留历史来源关联。
3. 两类条目可挂任意节点，新业务线自动创建无期限待办池。
4. 每线一份 Notes；节点正文与条目批注真实写入，按节点、条目分层，自动标注名称与节点截止时间；升线移动对应正文；纯完成不写纪要。
5. 节点、条目快速完成和删除；节点根据全部条目完成推导，项目和业务线必须手动完成、删除额外确认。
6. 今日首页与实际表单快速创建，先写内容再绑定业务线；节点、条目右键支持删除、编辑、添加批注。

软件定位是明确未来下一步，不维护无限历史树；框架为项目下多条独立业务线与有限层级。长期规则已固化至 AGENTS.md。

## 验收

- 标题即可收集，默认入池，不伪造时间或当天计划。
- 会议纪要、创建批注、实际推进批注和右键批注落入同一份 Markdown 原文。
- 三类升线不复制身份或内容，原线解除关系，新线继续工作。
- 完成节点不自动完成业务线；重新打开无需修改实际历史。
- 删除解除实际引用，保留时间和纪要；批量删除范围和外部冲突受检查。
- 跨文件中断可恢复，重试不重复移动、追加或创建。
- 旧示例一次性改为新结构，后续无旧契约、兼容分支或迁移工具。
