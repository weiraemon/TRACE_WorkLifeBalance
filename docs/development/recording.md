更新素材时保持同一组示例名称，加入步骤说明和操作位置高亮，避开真实目录及私人数据。以下是重新录制连续操作视频并导出 GIF 的方法。

## Windows：用 ScreenToGif

从 [ScreenToGif 官网](https://www.screentogif.com/)安装或下载便携版。

1. 启动 CHAOS，连接专门的示例目录。可用 `npx tsx scripts/sample-vault.ts E:\CHAOS-Demo` 向空目录生成当天数据。
2. 浏览器缩放设为 100%，隐藏书签栏；只录页面内容，避开地址栏、真实路径与私人资料。
3. 打开 ScreenToGif 的「录像机」，把录制框对准内容区域，设置约 1280 × 800、12～15 fps。
4. 开始录制，停留约 1 秒后操作。每段只演示一件事，控制在 8～12 秒；结束时停留约 2 秒，让人看清结果。
5. 停止后进入编辑器，裁掉多余区域，删掉等待、失误与重复帧；需要时保留鼠标或点击提示。
6. 另存为循环播放的 GIF，先用自动配色与重复帧优化。建议控制在 5 MB 左右；过大时优先缩短片段，再降低尺寸或帧率，并检查中文仍然清晰。

GIF 适合 README 自动播放。较长的演示建议导出 MP4，通过 GitHub 编辑器上传为附件，再使用返回的视频链接；普通 Markdown 图片语法不能直接播放 MP4。

## 适合 CHAOS 的三个短片段

| 片段           | 操作顺序                                   | 让读者看见什么                         |
| -------------- | ------------------------------------------ | -------------------------------------- |
| 从要求到下一步 | 工作空间 → 新增节点 → 添加 TODO → 勾选完成 | 业务线如何推进，节点如何随条目完成     |
| 记录真实工作   | 今日 → 填写事件与时间 → 关联事项 → 保存    | 记录进入实际时间线，计划与实际分别呈现 |
| 两种主题       | 工作空间 → 齿轮「备份」→ 静蓝 → 关闭设置   | 同一份工作内容在暖绿与静蓝下的效果     |

录制前把内容准备好，操作放慢，减少鼠标绕行。每个片段录两三次，选最顺的一次即可。

## 放进 README

将导出的 GIF 保存为 `docs/media/workflow.gif` 后，在 README 中插入：

```markdown
![沿业务线添加下一步并完成事项](docs/media/workflow.gif)
```

GitHub 图片缓存可能延迟更新，必要时换一个文件名。静态总览建议保留，动图用来展示具体动作；三张图或短片段足够说明产品。
