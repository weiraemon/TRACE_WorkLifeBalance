# Android 业务覆盖核对（v0.1.7）

2026-11-05 基于 main `070fc3c` 及 v0.1.7 发布配置，逐项核对实际页面、Android 平台路由与标准业务命令。核心工作流程已经覆盖。QQ／微信消息与 AI 服务之外，资源附件入口、完整目录导入、后台同步和存储提供方仍有边界。

| 能力                                                             | Android 当前情况                                                                                           | 差距或边界                                                                                                         |

| 项目／业务线创建、编辑、手动结束／重开、确认删除                 | 已有项目清单、重要性圆点、加号、更多菜单及共用表单                                                         | 手机没有桌面拖拽；业务线、条目移动与排序使用“移动／排序”等价入口                                                   |
| 节点／TODO／IDEA、To／From 联系人、日期、时刻、标签和重要性      | 已接入共用表单与服务                                                                                       | 条目仍无独立时刻，待办池固定在线尾，沿用现有规则                                                                   |

## 仍需实际设备验证的内容

模拟器已覆盖目录授权、离线重启与强制终止、发布中断恢复、第三种内容冲突、严格 UTF-8 和目录独占。真机、厂商后台回收、软键盘遮挡、授权撤销后的所有恢复路径、磁盘满和真实断电尚未形成完整验收；这些是验证缺口，不能据此断言相应保护没有实现。

独立普通笔记的界面入口和复盘文章独立编辑属于两端共同缺口。Android 尚未接入 Windows 已有的 QQ／微信读取与 AI 消息处理能力。后续新增继续复用同一共享底座。
