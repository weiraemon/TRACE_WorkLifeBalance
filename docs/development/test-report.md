## 当前交互与数据契约

节点只保存截止日期与截止时刻，是时间线上的点，不保存开始时间或持续时长；待办不重复填写时间。工作空间按截止日期 / 时刻排序。今日左侧按分钟定位截止点，点击节点可向左展开只读待办；未设时刻单独列出。计划与实际共用 00:00–24:00 刻度，只有实际允许录入、拖动和拉伸。

实际区块保存开始、结束时间和事件，可关联一个或多个待办。推进但未完成的 ID 保存到 workedTodoIds，本次完成的 ID 保存到 completedTodoIds，同一区块不重复保存同一个 ID。一个待办可以分多段推进，完成证据保持唯一；区块直接显示关联待办名称，项目归属从两类关联并集推导。完成状态不重复写入待办文件。

七种记录类型保持不变。节点开始字段已经移除，严格契约会对含已删除字段的记录显示诊断；没有批量迁移或改写真实 Vault。
